# 🚀 Resume Analyzer AI

### Intelligent Resume Screening & Job Matching System

Resume Analyzer AI is an AI-powered web application that analyzes resumes, compares them with job descriptions, identifies missing keywords, and provides actionable suggestions to improve resume quality.

## ✨ Features

- **Resume Upload:** Supports PDF and DOCX files.
- **Resume Validation:** Checks whether uploaded documents appear to be resumes.
- **Resume Quality Score:** Evaluates resume structure and content.
- **Job Match Score:** Estimates compatibility between a resume and a job description.
- **Keyword Analysis:** Identifies matched and missing job-related keywords.
- **Improvement Suggestions:** Provides practical recommendations.
- **Resume Feedback:** Offers detailed feedback and before-and-after suggestions.
- **Visual Analytics:** Displays interactive charts.
- **Report Downloads:** Generates PDF and JSON analysis reports.

## ⚙️ Installation

Clone the repository:

```bash
git clone https://github.com/abhiram577/resume-analyzer-ai.git
```

Navigate to the project folder:

```bash
cd resume-analyzer-ai
```

Install dependencies:

```bash
pip install -r requirements.txt
```

Run the application:

```bash
streamlit run app.py
```

## 📊 How It Works

1. Upload your resume in PDF or DOCX format.
2. Paste the job description.
3. Click **Analyze My Resume**.
4. Review resume quality and job match scores.
5. Explore matched and missing keywords.
6. Read improvement suggestions.
7. Download your analysis report.

## ⚠️ Important Note

The resume quality and job match scores are heuristic estimates generated by this application. They are not official ATS scores and do not guarantee recruitment outcomes.
